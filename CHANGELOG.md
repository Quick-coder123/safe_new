# 📝 CHANGELOG

## [Версія 2.0.0] - 2026-11-01

### 🔐 Безпека
- Підписані (HMAC) сесії адміністраторів замість непідписаного JSON у cookie
- `middleware.ts` захищає всі непублічні API, CSRF-перевірка `Origin`
- Видалено всі `*-temp`, `debug`, `test`, `fix-*`, `init-*` ендпоінти без авторизації
- Серверний доступ до бази через `SUPABASE_SERVICE_ROLE_KEY`, міграція вмикає RLS
- Тимчасові паролі генеруються криптографічно стійко на сервері
- Обмеження спроб входу, вимоги до складності пароля
- `/api/create-admin` працює лише для порожньої бази
- Хеші паролів більше не повертаються в API

### ✨ Додано
- Журнал змін (вкладка «Журнал змін»), таблиця `admin_audit_log`
- Реквізити (отримувач, ЄДРПОУ, IBAN, призначення, посилання на оплату страхування) зберігаються в налаштуваннях
- Перевірка IBAN (UA, 29 символів, контрольна сума mod 97) та ЄДРПОУ
- Додавання/видалення категорій сейфів і діапазонів страхування
- Попередження про термін понад 365 днів та відсутній тариф страхування
- Кнопка «Перенести на робочий день», якщо дата закінчення — вихідний
- Юніт-тести (Vitest) та CI на GitHub Actions

### 🔧 Змінено
- Тарифи за замовчуванням відповідають ТЗ
- Суми округлюються до копійок
- Одна схема БД `database/schema.sql` + міграції замість 15 розрізнених SQL-файлів
- Документація зведена в `docs/`

## [Версія 1.1.0] - 2025-08-01

### ✨ Додано
- **Модальне вікно копіювання credentials** для нових адміністраторів
- **Кнопки копіювання** логіна та паролю окремо
- **Кнопка "Копіювати обидва"** для швидкого копіювання
- **Покращений UI** для створення адміністраторів
- **Безпечна передача паролів** (хешування на сервері)

### 🔧 Змінено
- `create-admin` API тепер приймає як `password`, так і `password_hash`
- Перенесено хешування паролів з клієнта на сервер
- Покращено UX при створенні нових адміністраторів

### 🐛 Виправлено
- Проблема з bcryptjs в клієнтському коді
- Помилка білда через серверні модулі в браузері
